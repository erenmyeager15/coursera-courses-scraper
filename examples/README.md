# US learning research — synthetic previews

These three local inputs use **invented developer-authored course facts**. They do
not fetch Coursera/Udemy, represent real recommendations or verify a data licence.
No demo creates dataset rows or course-result events. Actor Start and platform
usage still apply; demos are not guaranteed free or profitable.

- `us-skills-comparison.json`: exact supplied Python/SQL/data-analysis tag coverage,
  missing evidence, difficulty and entered-hours review.
- `us-learning-budget.json`: one-time versus catalog-subscription context, three
  assumed subscription periods and an entered $60 per-learner budget. No completion
  or certificate guarantee; catalog access is not summed once per course.
- `us-catalog-change-review.json`: matching supplied quote/skill/hour/availability
  changes, with promotional prices kept separate.

Use `COURSE_REPORT`, `REPORT.md` and the four CSV artifacts, not the empty demo
dataset. Every artifact, including empty CSV headers, carries synthetic provenance.
Import is available only on the full Actor input and requires licensed JSON/CSV,
an export source label and explicit rights confirmation. Demo pages must keep
`mode` fixed to `demo`; never auto-check import rights or silently switch old tasks.

The files and example-page definitions are prepared locally, **not published**.
